# Logo Placeholder Instructions

## Required Logo Files

Create the following logo image files for the super admin app:

### 1. logo-superadmin.png
**Purpose**: Main logo for super admin panel
**Dimensions**: 200x50px (or maintain 4:1 ratio)
**Location**: `/public/images/logo-superadmin.png`

**Design Specifications**:
- Background: Transparent PNG
- Text: "PatLinks" in professional font
- Subtitle: "Super Admin" in smaller text
- Color Scheme:
  - Primary: White (#ffffff) or Light Slate (#f1f5f9)
  - Accent: Blue-purple gradient (#3b82f6 to #8b5cf6)
- Style: Modern, clean, professional

**Layout Options**:

Option A - Horizontal:
```
[Shield Icon] PatLinks
              SUPER ADMIN
```

Option B - Badge Style:
```
PatLinks
[SA Badge with shield]
SUPER ADMIN
```

Option C - Minimal:
```
[P] PatLinks Super Admin
```

### Design Tools

#### Quick Method - Using Canva
1. Create 800x200px design (will resize down)
2. Add text "PatLinks" in bold modern font (e.g., Inter, Poppins)
3. Add "Super Admin" subtitle in lighter weight
4. Add shield or badge icon
5. Apply gradient or solid color
6. Export as PNG with transparent background
7. Resize to 200x50px

#### Professional Method - Using Figma/Illustrator
1. Create artboard: 200x50px
2. Add your logo design elements
3. Use vector graphics for scalability
4. Export as PNG @2x (400x100px) for retina displays
5. Export standard PNG (200x50px)

### SVG Template

If you want to create a simple text-based logo in SVG:

```svg
<svg width="200" height="50" viewBox="0 0 200 50" xmlns="http://www.w3.org/2000/svg">
  <defs>
    <linearGradient id="textGrad" x1="0%" y1="0%" x2="100%" y2="0%">
      <stop offset="0%" style="stop-color:#3b82f6" />
      <stop offset="100%" style="stop-color:#8b5cf6" />
    </linearGradient>
  </defs>

  <!-- Main Text -->
  <text x="10" y="28" font-family="Arial, sans-serif" font-size="24"
        font-weight="900" fill="url(#textGrad)">PatLinks</text>

  <!-- Subtitle -->
  <text x="10" y="44" font-family="Arial, sans-serif" font-size="10"
        font-weight="500" fill="#94a3b8">SUPER ADMIN</text>

  <!-- Shield Icon -->
  <path d="M 175 10 L 185 10 L 190 15 L 190 25 C 190 30 185 35 180 40 C 175 35 170 30 170 25 L 170 15 L 175 10"
        fill="none" stroke="url(#textGrad)" stroke-width="1.5"/>
</svg>
```

Convert to PNG using:
- CloudConvert (https://cloudconvert.com/svg-to-png)
- Online-Convert (https://www.online-convert.com)
- Or use design software

### Implementation Checklist

After creating your logo:
- [ ] Create high-resolution version (400x100px @2x)
- [ ] Create standard version (200x50px)
- [ ] Ensure transparent background
- [ ] Optimize file size (use TinyPNG or similar)
- [ ] Test on dark background (should be visible)
- [ ] Test on light background (for versatility)
- [ ] Save as `logo-superadmin.png` in `/public/images/`

### File Optimization

Before deploying, optimize your PNG:
- Use **TinyPNG** (https://tinypng.com) - Reduces file size by 60-80%
- Use **Squoosh** (https://squoosh.app) - Google's image optimizer
- Use **ImageOptim** (Mac) or **FileOptimizer** (Windows)

Target file size: Under 10KB for optimal loading

### Usage in App

The logo will be used in:
- Navigation header/sidebar

- Email templates (if applicable)
- Export documents/PDFs
- Loading screens

Make sure it's legible at small sizes (50x12px minimum).
